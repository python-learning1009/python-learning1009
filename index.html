01 / Overview

This course introduces the foundations of programming through Python. You will learn variables, expressions, data types, conditions, functions, loops, strings, and lists—then combine them to solve manageable real-life and business problems.

Class time blends short lectures, live coding, guided practice, group work, and AI-assisted learning. You will read, run, test, explain, and improve code rather than treating generated answers as a black box.

04 / Group project

Build something interesting together

Presentations will take place on October 26 and 28, with the presentation order determined by random draw.

≈ 6students per team 7 minpresentation 2–3 minQ&A
1

Define the problem

Identify the user, real-life need, inputs, outputs, rules, and a manageable scope.

2

Build and test

Create a clear command-line program, test different examples, and divide the work fairly.

3

Explain the solution

Present the design, walk through the code, demonstrate three test cases, and answer questions.
